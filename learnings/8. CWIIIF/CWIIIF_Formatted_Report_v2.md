# Exact Deterministic Optimization of the CWIIIF Algorithm for Small-Scale Multilayer Networks

## Introduction to Multilayer Influence Dynamics

The structural analysis of complex systems—ranging from intermodal urban transit grids to cellular biological pathways and multilayered financial counterparty networks—has undergone a profound paradigm shift over the past decade. Classical network science predominantly relied on monolithic, single-layer graphs that flattened heterogeneous modes of interaction into a singular, homogenized topological space. While computationally convenient, this reductionist approach fundamentally erases the multidimensional nuance of modern physical and logical systems. In reality, entities interact concurrently across overlapping, distinct layers. An individual may be connected via a physical workplace hierarchy, a digital social media platform, and a recreational organization simultaneously, just as a genetic sequence operates across varied metabolic and regulatory pathways.To accurately capture these overlapping architectures, the field has universally adopted multilayer network frameworks, particularly multiplex and multisliced topologies. In a strictly multiplex network, a uniform set of nodes exists simultaneously across all network layers, but the edges connecting those nodes vary drastically from one topological dimension to the next. Within these complex environments, the "influence maximization problem" seeks to identify the optimal subset of nodes (seeds) that, when activated, can trigger the largest possible cascade of information, behavioral adoption, or epidemiological contagion across the entire system.The Coupling Weighted Intra-layer and Inter-layer Influence Factors (CWIIIF) algorithm was introduced as a pioneering methodology designed to identify these influential nodes. It attempts to bridge the gap between local structural importance and macroscopic layer significance. However, the baseline CWIIIF architecture introduces severe topological blind spots and relies heavily on stochastic approximations to remain computationally tractable for massive, billion-node datasets. While randomized approximations such as Vapnik-Chervonenkis (VC) dimension sampling are strictly necessary for web-scale graphs, they are mathematically destructive for tightly bounded, small-scale networks.For high-stakes network environments containing fewer than 10,000 nodes ($N < 10,000$)—such as specialized corporate communication grids, localized biological connectomes, elite financial ecosystems, or bespoke military routing networks—stochastic approximation is completely unnecessary. Modern computational hardware can seamlessly execute exact combinatorial, spectral, and cubic-time operations at this scale. Consequently, applying the baseline CWIIIF algorithm to these environments introduces inexcusable statistical biases, particularly when navigating unique topological edge cases.This report provides a comprehensive, deterministic optimization of the CWIIIF framework. By systematically deconstructing the baseline algorithm's mathematical failures across isolated cliques, asymmetric flow sinks, cross-layer boundaries, and dimensionality collapse, this analysis details exact, non-probabilistic structural upgrades. Through the integration of the Entropy Weight Method (EWM), Harmonic Global Efficiency, Hodge Laplacians, exact Supra-Adjacency evaluations, and Pareto-optimal sorting mechanisms, the CWIIIF algorithm is mathematically hardened to deliver perfect deterministic exactness for networks where $N < 10,000$.
## Mathematical Foundations of the Baseline Architecture

To rigorously evaluate the edge cases that trigger the failure of the baseline CWIIIF algorithm, it is first necessary to dissect its foundational mathematical mechanics. The algorithm operates on a multiplex network denoted as $G=(L, V, E)$, where $L$ represents the finite set of layers, $V$ constitutes the set of nodes, and $E$ signifies the collection of intra-layer edges. The fundamental multiplex assumption asserts that $V^{[1]} = V^{[2]} = \dots = V^{[L]}$, indicating perfect node alignment across all topological dimensions, although the specific edge configurations $E^{[\alpha]}$ may vary drastically.The baseline CWIIIF operates through a rigid, sequential three-phase pipeline intended to map multi-dimensional topological interactions into a singular scalar ranking.
### Phase 1: Macro-Level Layer Weighting

The first phase calculates a weight for each layer, denoted as $W(\alpha)$, by synthesizing three distinct normalized environmental factors.The Normalized Active Node (NAN) metric quantifies the density of highly connected hubs. A node $i$ residing in layer $\alpha$ is defined as "active" strictly if its local degree $K_i^{[\alpha]}$ exceeds the average degree $\langle K^{[\alpha]} \rangle$ of the entire layer. The active state is binary:

$$b_i^{[\alpha]} = \begin{cases} 1, & \text{if } K_i^{[\alpha]} > \langle K^{[\alpha]} \rangle \\ 0, & \text{otherwise} \end{cases}$$

The NAN value for layer $\alpha$ is simply the ratio of its active nodes to the total active nodes across all network layers.Following this, the algorithm evaluates transmission efficiency via the Normalized Active Path (NAP) metric. The active path attempts to calculate the exact shortest topological distance $d_{ij}^{[\alpha]}$ between all valid, non-isolated node pairs. The average of these minimal paths defines the layer's raw transmission capacity:

$$d^{[\alpha]} = \frac{\sum_{i,j=1, j \neq i}^N d_{ij}^{[\alpha]}}{2N}$$

This raw score is subsequently normalized against the overarching network structure.The final component of the layer weight is the Normalized Inter-layer Communication Intersection (NICI). This metric captures cross-layer structural redundancy by computing the Jaccard similarity coefficient of the edge sets between layer $\alpha$ and all other layers $\beta$. The intersection of these binary edge sets is divided by their union:

$$Jaccard^{[\alpha]} = \sum_{\beta=1, \beta \neq \alpha}^L \frac{\vert{}E^{[\alpha]} \cap E^{[\beta]}\vert{}}{\vert{}E^{[\alpha]} \cup E^{[\beta]}\vert{}}$$

The final layer weight $W(\alpha)$ is derived by executing a uniform, unweighted summation of these three normalized components: $W(\alpha) = NAN^{[\alpha]} + NAP^{[\alpha]} + NICI^{[\alpha]}$.
### Phase 2: Micro-Level Intra-Layer Influence Vectors

The second phase transitions from macro-level layer assessment to micro-level node evaluation, computing an intra-layer influence vector for each entity. The algorithm achieves this by isolating each layer completely and calculating a composite centrality score, $KB_i^{[\alpha]}$, which is a linear combination of normalized K-shell decomposition (KS) and Betweenness Centrality (BC).K-shell measures topological coreness by iteratively peeling away peripheral nodes with the lowest degrees, revealing dense subgraphs. Betweenness Centrality measures global bridging capacity by quantifying the fraction of all possible shortest paths that intersect the specific node. By summing a localized density metric with a global routing metric ($KB_i^{[\alpha]} = KS_i^{[\alpha]} + BC_i^{[\alpha]}$), the algorithm generates an influence profile for the node strictly within the confines of layer $\alpha$.
### Phase 3: Dimensionality Collapse

The third and final phase executes a massive dimensionality reduction, compressing the multi-dimensional vector $KB_i = [KB_i^{[1]}, \dots, KB_i^{[L]}]$ into a final scalar metric. The Total Influence ($TI_i$) of a given node is mathematically defined as the dot product of its intra-layer influence vector and the previously computed layer weights:

$$TI_i = \sum_{\alpha=1}^L KB_i^{[\alpha]} \times W(\alpha)$$

This singular scalar value dictates the final ordinal ranking of the nodes, determining which entities are selected for influence maximization.
## Algorithmic Paralysis: Deconstructing Baseline Edge Cases

While the baseline CWIIIF framework performs adequately on highly uniform datasets, its reliance on specific heuristic constraints, uniform weighting, and linear scalarization causes catastrophic mathematical failure when exposed to irregular network geometries. Regardless of whether the network contains 100 nodes or 1,000,000 nodes, the baseline algorithm will produce highly biased or fundamentally incorrect rankings in the following four deterministic edge cases.
### The "Elite Clique" Dataset and the Isolated Node Exception

A fundamental prerequisite of the baseline algorithm is its constraint to strictly multiplex networks, where every node exists concurrently across all layers. However, in highly specialized empirical systems—such as a multimodal transportation grid combining ubiquitous public bus stops (Layer A) with highly exclusive international airport terminals (Layer B)—the vast majority of nodes do not actively participate in every interaction modality.When forced into a multiplex structure, entities that do not participate in a specific layer manifest as completely isolated vertices with a degree of zero. To prevent infinite path lengths from breaking the mathematical calculation of the average shortest path, the baseline CWIIIF algorithm programmatically excludes isolated nodes from the active path (NAP) computation.This specific exception introduces a fatal statistical bias. Consider a 10,000-node network where Layer $\alpha$ represents an exclusive, hyper-specific interaction modality applicable only to an "elite clique" of 100 interconnected nodes, leaving the other 9,900 nodes completely isolated. The baseline algorithm ignores the 9,900 isolated nodes and calculates the average shortest path exclusively over the dense 100-node clique. Consequently, the active path length for Layer $\alpha$ becomes artificially deflated, making the layer mathematically appear exponentially more efficient and pervasive than it actually is. This anomaly incorrectly inflates the NAP coefficient for Layer $\alpha$, corrupting the $W(\alpha)$ weighting and drastically skewing the entire influence ranking hierarchy.
### Asymmetric Flow Datasets and Network Sinks

The foundational CWIIIF algorithm is strictly constrained to unweighted and undirected topologies. This is a crippling limitation for modeling realistic complex systems where interaction pathways exhibit specific directionality, such as Twitter follower graphs, financial contagion networks, or academic citation systems.By enforcing an undirected constraint and relying on unweighted Breadth-First Search (BFS) logic to determine active paths and Betweenness Centrality, the algorithm mathematically assumes that all influence is perfectly bidirectional. This fatal flaw causes the algorithm to systematically overestimate the global reachability of nodes located in "network sinks". A network sink is a node that receives massive inward connections (e.g., a highly cited research paper or a widely followed passive social media account) but emits very few outward connections. Because undirected Betweenness Centrality calculates paths passing through a node irrespective of edge orientation, network sinks are falsely assigned massive centrality scores. In the context of influence maximization—which requires triggering an outward cascade—these nodes are structurally useless, yet the baseline algorithm ranks them as premier spreaders.
### The "Boundary Bridge" Edge Case

While the CWIIIF framework acknowledges inter-layer edges that connect a node to its concurrent self across different layers, it structurally ignores them during the second phase of execution. The algorithm mandates that intra-layer influence vectors (K-shell and Betweenness Centrality) must be calculated on each layer completely independently.By severing all inter-layer connections before computing centrality, the algorithm falls victim to the topological "boundary problem". An entity might act as the exclusive structural bridge linking a massive component in Layer A to a completely disparate massive component in Layer B. However, because the intra-layer centrality algorithms are explicitly barred from "seeing" cross-layer topological connections, this critical bridge node is evaluated purely on its local connectivity within the isolated layers. If the node only possesses a degree of one in Layer A and a degree of one in Layer B, it will score abysmally on both the KS and BC metrics. The algorithm remains entirely blind to the node's pivotal bridging capability, resulting in a deflated Total Influence ($TI_i$) score that fails to capture its macroscopic systemic importance.
### Redundant Seed Budgets and Dimensionality Collapse

If the baseline algorithm is utilized to generate a seed set for influence maximization under competitive routing constraints (e.g., a viral marketing campaign with a strict budget of 50 initial seeds), it will fail to provide optimal spatial diversity.This failure stems from the terminal stage of the algorithm, which collapses the multidimensional influence vector $KB_i$ into a single scalar value ($TI_i$) via a dot product. While scalarization provides a computationally convenient flat list for sorting, it triggers catastrophic information loss. The final scalar metric completely blinds the selection process to the spatial distribution of influence.For example, Node A might derive a $TI_i$ score of 0.90 by acting as the absolute central hub exclusively in Layer 1. Node B might derive the exact same score by operating as a secondary hub in the exact same echo chamber in Layer 1. If the algorithm selects seeds purely based on the collapsed scalar rankings, it is highly likely to select both Node A and Node B. This guarantees massive influence overlap, squandering the seed budget on redundant topological clusters while leaving the other network layers entirely untargeted, resulting in severely diminishing returns.

## Deterministic Structural Improvements for Bounded Networks ($N < 10,000$)

### 1. Resolving the Isolated Node Exception: Harmonic Path Averaging

The standard mathematical definition of average active path length fails in disconnected graphs because the shortest path distance $d_{ij}$ between nodes in disconnected components (or isolated nodes) evaluates to infinity ($\infty$). The baseline CWIIIF's workaround—excluding these pairs entirely—corrupts the statistical representation of the layer.To fix this deterministically without resorting to heuristic pivot approximations, the optimized algorithm replaces the standard average shortest path length calculation with Harmonic Global Efficiency. Harmonic averaging measures the efficiency of information exchange by evaluating the inverse of the shortest path lengths. For any given layer $\alpha$, the Harmonic Global Efficiency $E_{glob}^{[\alpha]}$ is rigorously defined as:

$$E_{glob}^{[\alpha]} = \frac{1}{N(N-1)} \sum_{i \neq j} \frac{1}{d_{ij}^{[\alpha]}}$$

Under this framework, when two nodes $i$ and $j$ are entirely disconnected, their topological distance $d_{ij} = \infty$. The harmonic calculation naturally evaluates their reciprocal distance to strictly zero ($\frac{1}{\infty} = 0$). This mathematical property elegantly preserves the absolute total node count $N$ in the denominator without breaking the summation.By quantifying the exact efficiency of the layer across all entities, Harmonic Global Efficiency heavily penalizes sparse, disconnected layers filled with isolated nodes. The normalized Harmonic NAP coefficient is then calculated by comparing a layer's exact harmonic efficiency against the sum of the efficiencies across all layers:

$$NAP^{[\alpha]}_{Harmonic} = \frac{E_{glob}^{[\alpha]}}{\sum_{\beta=1}^L E_{glob}^{[\beta]}}$$

This effectively neutralizes the "Elite Clique" edge case, ensuring that highly fragmented layers receive a mathematically appropriate, diminished transmission weight rather than an artificially inflated one.
### 2. Directed Formulations and Cross-Layer Bridges: Supra-Adjacency and Mixed Degree Decomposition

To transcend the baseline limitations regarding unweighted and undirected graphs, the structural metrics operating within the CWIIIF framework must be mathematically generalized to handle asymmetric flow.To resolve the network sink anomaly during the K-shell decomposition process, the algorithm must transition to Mixed Degree Decomposition (MDD). Traditional K-shell iteratively peels nodes strictly based on total undirected degree. In directed information propagation architectures, the out-degree fundamentally dictates transmission capacity. However, relying exclusively on out-degree discards critical structural history regarding the node's local environment. MDD intelligently combines the residual degree (active edges connecting to surviving nodes in the current shell) and the exhausted degree (edges connecting to already-peeled peripheral nodes).In a directed MDD implementation, the mixed out-degree metric $k_{i, out}^{(m)}$ for a node $i$ during any iterative peeling stage is defined by a peeling parameter $\lambda \in [0, 1]$:

$$k_{i, out}^{(m)} = k_{i, out}^{(residual)} + \lambda \cdot k_{i, out}^{(exhausted)}$$

By systematically re-evaluating the true outward spreading capacity of a node while preserving the topological memory of its local environment (typically utilizing $\lambda = 0.7$), MDD severely penalizes network sinks (where $k_{out} \approx 0$) while preserving true influential spreaders. Nodes that fall below the dynamic threshold join the current shell before the threshold advances, allowing for ultra-fine-grained ranking differentiation.To resolve the "Boundary Bridge" edge case, the practice of calculating Betweenness Centrality on completely isolated layers must be terminated. The structural isolation must be replaced by a holistic spectral evaluation utilizing a massive Supra-Adjacency Matrix ($\mathcal{A}_{supra}$).For a multiplex network, the supra-adjacency matrix is a large block matrix where the main diagonal blocks contain the intra-layer adjacency matrices $A^{[\alpha]}$ for each layer, and the off-diagonal blocks contain the inter-layer coupling matrices $C^{[\alpha, \beta]}$ representing the cross-layer identity edges. If the network possesses $N$ nodes and $L$ layers, $\mathcal{A}_{supra}$ is an $(N \times L) \times (N \times L)$ matrix defined as:

$$\mathcal{A}_{supra} = \bigoplus_{\alpha=1}^L A^{[\alpha]} + \sum_{\alpha \neq \beta} C^{[\alpha, \beta]}$$

Because the network is bounded below 10,000 nodes, applying Brandes' exact algorithm directly to the full directed $\mathcal{A}_{supra}$ matrix is computationally tractable. By calculating Betweenness Centrality on the unified supra-graph, the algorithm natively evaluates shortest paths that traverse horizontally through Layer A, bridge vertically across the inter-layer coupling matrix $C^{[\alpha, \beta]}$, and continue horizontally through Layer B. This guarantees that nodes acting as critical cross-layer boundaries receive high centrality scores commensurate with their true systemic importance, completely resolving the blind spot.
### 3. Higher-Order Topological Coupling via Hodge Laplacians

The baseline CWIIIF quantifies inter-layer similarity (NICI) via the Jaccard coefficient, which strictly measures the binary overlap of 1-simplices (edges) between isolated layers. This represents a topologically primitive perspective. $$\mathcal{L}_1 = B_1^\top B_1 + B_2 B_2^\top$$

### 4. Dynamic Objective Weighting via the Entropy Weight Method (EWM)

The baseline CWIIIF calculation of the final layer-weighted coefficient $W(\alpha)$ is achieved through a rigid, unweighted linear summation: $W(\alpha) = NAN^{[\alpha]} + NAP^{[\alpha]} + NICI^{[\alpha]}$. This heuristic assumes that active node density, transmission latency, and topological overlap are perpetually of identical relevance across all possible datasets. EWM is a highly sophisticated, data-driven multi-criteria decision-making algorithm that calculates objective criterion weights strictly by measuring the information entropy—the degree of statistical dispersion or uncertainty—of each individual metric across the network.The deterministic EWM process operates sequentially. First, the evaluation matrix containing the raw values for NAN, Harmonic NAP, and NTR for all $L$ layers is standardized via min-max normalization to eliminate scale variance. This creates a normalized matrix where all values reside within a $[0, 1]$ interval. Let $x_{\alpha j}$ denote the normalized value of layer $\alpha$ for metric $j$. The probability component $P_{\alpha j}$ is calculated as the proportion of that layer's value relative to the total sum of that metric across all layers:

$$P_{\alpha j} = \frac{x_{\alpha j}}{\sum_{i=1}^L x_{ij}}$$

Following this, the Shannon information entropy $E_j$ for each specific criterion is strictly quantified using the logarithmic formulation:

$$E_j = -\frac{1}{\ln(L)} \sum_{\alpha=1}^L P_{\alpha j} \ln(P_{\alpha j})$$

(Note: To maintain absolute mathematical continuity, if $P_{\alpha j}$ evaluates exactly to zero, L'Hopital's limit dictates that $\lim_{P \to 0} P \ln(P) = 0$, ensuring the calculation does not encounter an undefined error).Finally, the objective weight $\omega_j$ for each criterion is calculated by evaluating the degree of divergence ($1 - E_j$) from maximum entropy:

$$\omega_j = \frac{1 - E_j}{\sum_{k=1}^m (1 - E_k)}$$

The mathematical brilliance of the EWM lies in its seamless adaptability. If a specific metric (e.g., the NAN active node density) is virtually identical across all $L$ layers in a specific dataset, its calculated information entropy $E_j$ will approach 1.0 (maximum uncertainty). The EWM algorithm will subsequently assign it a near-zero weight $\omega_j$, deterministically recognizing that the metric completely lacks the variance necessary to discriminate layer importance. Conversely, if the Harmonic NAP exhibits massive variance across layers—indicating that some layers are radically more efficient at global transmission—its entropy will be extremely low, prompting EWM to assign it a mathematically dominant weighting coefficient.By integrating EWM, the computation of the layer weight becomes a fully dynamic, objective calculation:

$$W(\alpha) = \omega_1 NAN^{[\alpha]} + \omega_2 NAP_{Harmonic}^{[\alpha]} + \omega_3 NTR^{[\alpha]}$$

This completely resolves the rigidity of the baseline formulation, allowing the algorithm to seamlessly adapt to the unique statistical variance of any input dataset without introducing a single element of stochasticity or human bias.
